# Мой день

Органайзер, который сам раскладывает дела по дню и освобождает время для себя.

- **Повседневные задачи** (работа, душ, тренировка) и **вариативные** (стирка, уборка), которые нужны раз в несколько дней.
- План строится автоматически: сначала дела с точным временем и цепочки «сразу после», потом остальное по важности. Фоновые дела (стирка, посудомойка) запускаются пораньше, чтобы параллельно делать другое.
- Будни и выходные определяются сами, у каждого свой подъём и отбой.
- Напоминание «Вы сделали…?» с кнопками ✓ и ✗, если время задачи прошло, а отметки нет.

## Как устроено

Статическое веб-приложение (PWA) без сборки: `index.html`, `css/`, `js/`, `sw.js`.

- `js/scheduler.js` — логика плана дня, чистые функции.
- `js/app.js` — интерфейс.
- `js/notify.js`, `sw.js`, `js/inbox.js` — уведомления и работа без интернета.

Данные пока хранятся на телефоне (localStorage). Синхронизация для двоих появится следующим шагом.

## Запуск и тесты

```sh
npm start   # http://localhost:8080
npm test    # тесты логики плана
```

После изменения файлов увеличьте `VERSION` в `sw.js`, чтобы телефоны подтянули новую версию.
